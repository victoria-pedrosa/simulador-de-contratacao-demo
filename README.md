# Demonstração — Simulador de custo de contratação

> Projeto de portfólio de **Victória Pedrosa**. **Demonstração** de simulador de custo de contratação — versão com dados fictícios (nomes, CNPJs, e-mails e IDs internos substituídos).

## Problema de negócio
Clientes pedem o custo real de contratar um funcionário e o cálculo manual é demorado.

## Antes x depois
| | Antes | Depois |
|---|---|---|
| Como é feito | Planilha preenchida e PDF montado à mão. | Script gera o PDF 'Estudo de Custo de Contratação' a partir da aba de simulação. |

## Ganho
- Estudo entregue ao cliente em minutos.

## Tecnologias
APIs REST, Google Apps Script, Google Drive, Google Sheets, Web App (HtmlService)

## Arquivos
- `Codigo.gs`

## Como usar
Crie um projeto no Google Apps Script, copie os arquivos `.gs`/`.html` e configure as Propriedades do script indicadas no código.
